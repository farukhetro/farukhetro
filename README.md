# 👋 About Me

I'm driven by curiosity and enjoy exploring new ideas, challenging assumptions, and solving real-world problems.

I enjoy working across **software, AI, products, automation, systems, and business** rather than limiting myself to a single technology or discipline.

My focus is simple:

> **Build useful things that solve real problems.**

I like taking ideas from **concept → research → implementation → deployment → real-world use**.

I believe the best projects are not necessarily the most complicated ones. They are the ones that are **useful, reliable, scalable, and actually used by people**.

### 🚀 What I'm Doing

* 🔭 Building **products that solve real-world problems**
* 🤖 Exploring **AI, automation, and intelligent systems**
* 🧠 Learning **system thinking, product design, and entrepreneurship**
* 🌱 Exploring **emerging technologies**
* 🛠️ Building **open-source developer tools**
* 👯 Looking to collaborate on **open-source and innovative products**
* 💡 Interested in combining **technology + business + automation**

A serverless AI image generation API powered by **Cloudflare Workers AI**.

```text
📝 Prompt
   ↓
⚡ API Request
   ↓
☁️ Cloudflare Worker
   ↓
🤖 Workers AI
   ↓
🎨 Generated Image
```

### Features

* 🆓 Free-tier AI image generation
* ⚡ Serverless architecture
* 🔐 API key authentication
* 📐 Multiple aspect ratios
* 🤖 AI model support
* 🌍 Cloudflare infrastructure
* 🛠️ Easy deployment

🔗 **[View Image Generation Project](https://github.com/farukhetro/Image-Generation)**

# 💡 Project Philosophy

I don't want to build projects just to have more repositories.

I want to build things that answer questions like:

```text
❓ Can this save someone time?

❓ Can this remove repetitive work?

❓ Can this make something easier?

❓ Can this become a useful product?

❓ Can other developers learn from it?

❓ Can this solve a real problem?
```

If the answer is yes, it's worth building.
